# data/network_500kv

Generated by running the scripts in `scripts/network_500kv/` in order.

## Detail

### `buses_500kv_raw.csv`
**Source:** PSS/E `ver2526pid.raw` (CAMMESA)

500 kV buses from the PSS/E base case with their electrical parameters.
One record per bus. Excludes buses with IDE=4 (isolated) and international buses.

| Field | Description |
|-------|-------------|
| `bus_id` | Numeric ID in PSS/E |
| `bus_name` | Bus name |
| `baskv_kv` | Base voltage (kV) |
| `ide` | Type: 1=PQ, 2=PV, 3=slack |
| `ide_desc` | Bus type description |
| `area` | CAMMESA electrical area |
| `vm_pu` | Base case voltage magnitude (pu) |
| `va_deg` | Base case voltage angle (degrees) |

---

### `lines_500kv_raw.csv`
**Source:** PSS/E `ver2526pid.raw` (CAMMESA)

500 kV lines and series compensators with impedances and ratings from the PSS/E base case.

| Field | Description |
|-------|-------------|
| `line_key` | Human-readable identifier: `BUS_I-BUS_J-CKT` |
| `bus_i` / `bus_j` | Terminal bus IDs |
| `ckt` | Circuit number (1, 2, 3...) |
| `r_pu` / `x_pu` / `b_pu` | Impedances in pu (Sbase=100 MVA) |
| `ratea_mva` | Thermal rating in MVA (NaN if not defined) |
| `len_km` | Length in km |
| `element_type` | `line` or `series_compensator` |
| `in_service` | True if the branch is in service |

---

### `trafos_500kv_raw.csv`
**Source:** PSS/E `ver2526pid.raw` (CAMMESA)

Transformers with at least one 500 kV winding. 3-winding transformers are decomposed
into two 2-winding transformers using the 500 kV winding as the common reference.

| Field | Description |
|-------|-------------|
| `trafo_key` | Human-readable identifier: `BUS_I-BUS_J-CKT` |
| `bus_i` | 500 kV bus (always the high-voltage side) |
| `bus_j` | Secondary bus (low-voltage side) |
| `ckt` | Circuit number |
| `origin` | `2W` (original) or `3W_decomp` (decomposed from 3-winding) |
| `r_pu` / `x_pu` | Impedances in pu (Sbase=100 MVA) |
| `sbase_mva` | Transformer base power in MVA |
| `in_service` | True if the transformer is in service |

---

### `buses_sec_raw.csv`
**Source:** PSS/E `ver2526pid.raw` (CAMMESA)

Secondary buses: all buses that appear as `bus_j` in `trafos_500kv_raw.csv`.

| Field | Description |
|-------|-------------|
| `bus_id` | Numeric ID in PSS/E |
| `bus_name` | Generated name: `PARENT_kVkV` or `PARENT_kVkV_N` |
| `bus_name_psse` | Original bus name in PSS/E |
| `baskv_kv` | Base voltage (kV) |
| `ide` | PSS/E bus type |
| `vm_pu` / `va_deg` | Base case voltage |
| `parent_bus_id` | `bus_id` of the 500 kV bus it connects to via transformer |

### `generators_mapped.csv`
**Source:** `09_map_generators.py`

Topological lookup table that maps each PSS/E generator unit to the nearest model bus.

| Field | Description |
|-------|-------------|
| `gen_key` | Unique PSS/E key: `bus_id_origin-gen_id` |
| `bus_name_origen` | Origin bus name in PSS/E |
| `carrier` | PyPSA technology type |
| `pg_mw` | Active dispatch in the PSS/E snapshot (MW) |
| `pt_mw` | Maximum installed capacity (MW) |
| `stat` | Status in the snapshot (1=in service, 0=out) |
| `match_type` | `direct` / `bfs` / `no_connection` |
| `bus_conexion500kv` | bus_id of the assigned model bus |
| `bus_conexion500kv_name` | Name of the destination model bus |
| `n_jumps` | BFS hops to the destination bus |
| `path` | PSS/E bus route from origin to destination |

### `generators_final.csv`
**Source:** `12_build_generators_final.py`

Definitive generator table for PyPSA. Merges `generators_readypypsa.csv` with rows
from `generators_manualpypsa.csv` that have `geosadi_name` and `bus_conexion500kv`
filled in.

The `nemo` field is resolved by joining `geosadi_name` → `Nombre` in GeoSADI's
`centrales_electricas.csv`. Units TG01, TG06 and TV07 of Agua del Cajón are assigned
`nemo = CAPE` (CAPEX Autoprod.) via reassignment applied in this script.

### `generators_2024.csv`
**Source:** `14b_build_generators_2024.py`

Generator table with real 2024 installed capacity from CAMMESA. This is the
generation input for the model from script 14b onwards.

| Field | Description |
|-------|-------------|
| `gen_key` | Unique PSS/E key |
| `bus_name_origen` | Origin bus name (with conflict overrides applied) |
| `geosadi_name` | Power plant name in GeoSADI |
| `nemo` | CAMMESA plant code |
| `bus_conexion500kv` / `bus_conexion500kv_name` | Model bus the unit connects to |
| `carrier` | PyPSA technology type |
| `p_nom` | Real installed capacity (MW) — 95th percentile of annual available_capacity_mw in CAMMESA |
| `lat` / `lon` | Geographic coordinates (WGS84) |

Notes:
- Salto Grande (SGDE): `p_nom` × 0.5 (binational plant Argentina/Uruguay)
- 18 units excluded due to name conflict with CAMMESA
- 25 units with no match in CAMMESA (auto-producers and plants outside the MEM)
- Total system `p_nom`: ~40,084 MW

### `loads_2024.csv`
**Source:** `15_build_loads_2024.py`

2024 hourly demand by 500 kV bus in long format. One row per bus per hour.

The `bus_name` values in the output match the bus index in `network_500kv.nc`
thanks to the bus coupler fusion applied during processing.

| Field | Description |
|-------|-------------|
| `bus_id` | 500 kV bus ID |
| `bus_name` | Bus name in the network |
| `datetime` | Timestamp in DD/MM/YYYY HH:MM format |
| `p_mw` | Demand in MW |

Coverage: 72 buses × 8,784 hours. 6 network buses have no demand in the source file
(series compensators and pass-through busbars with no associated distribution load).

System demand peak: 27,439 MW on 01/02/2024 at 14:00.

Clean and normalized 2024 hourly generation file from the MEM. Base input for
scripts 14b, 16 and 17.

| Field | Description |
|-------|-------------|

| `gas_available_capacity_mw` | Available capacity on natural gas (MW) |
| `PIND` | Independent capacity (MW) |

### `gen_profiles_2024.csv` *(external to GitHub)*
**Source:** `17_build_gen_profiles_2024.py`
**Local path:** `external_data_dir/gen_profiles_2024.csv`

Hourly availability profiles for all generator units in the model.
Input for the optimization (script 19). Units with no match in CAMMESA
(auto-producers, outside the MEM) do not appear in this file and are excluded from
the network by script 19 at load time.

| Field | Description |
|-------|-------------|
| `gen_key` | Unique unit key |
| `bus_conexion500kv_name` | Model bus the unit connects to |
| `carrier` | PyPSA technology type |
| `datetime` | Timestamp (DD/MM/YYYY HH:MM) |
| `p_max_pu` | Availability factor [0,1]. Solar/wind/biogas/biomass: `energy_mwh / p_nom`. Hydro/pumped_hydro/nuclear: `operated_energy_mwh / p_nom`. Remaining technologies: `available_capacity_mw / p_nom`. |

Coverage: ~577 units × 8,784 hours ≈ 5.3M rows.
